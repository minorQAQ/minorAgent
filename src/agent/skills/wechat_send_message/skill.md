# 微信消息发送操作指南

当用户任务涉及通过微信发送消息时，请严格按照以下步骤执行。

## 默认发送对象

- **默认接收人**：文件传输助手（即"文件传输助手"或用户明确指定的联系人）
- 若用户未指定发送对象，默认发送给**文件传输助手**
- 若用户指定了具体联系人，则发给该联系人

## 操作步骤

### 步骤 1：打开微信(注意，此步骤要按1、2、3分步进行)

1. 按下 `Win` 键打开开始菜单、搜索"微信"或"WeChat"、回车打开微信应用
2. 等待微信登录界面加载完毕（稍等 1 秒）
3. 点击登录并等待微信主界面加载完毕（稍等 5 秒）

### 步骤 2：搜索框搜索目标联系人

1. 在微信搜索框（通常在界面左上角或顶部区域）输入默认接收人名称（"文件传输助手"）或用户指定的联系人名称
2. 回车

### 步骤 3：输入并发送消息
#### 如果用户指定的是消息：
1. 输入用户指定的消息内容
2. 使用 `gui_tool` 按 `Enter` 键发送消息，或点击发送按钮
#### 如果用户指定的是文件：
1. 点击文件传输图标（通常在聊天输入框界面底部的文件夹图标）
2. 在弹出的文件选择浮窗中的文件名输入框中，输入用户指定的文件路径
3. 使用 `gui_tool` 按 `Enter` 键发送消息，或点击发送按钮
### 步骤 4：确认发送成功

1. 检查聊天窗口中是否出现了刚才发送的消息
2. 若已发送成功，关闭微信窗口（`Alt+F4` 或点击关闭按钮）
3. 告知用户消息已成功发送

## 注意事项

- 微信窗口如果被最小化，需要先恢复窗口再操作
- 发送前务必确认消息内容与用户要求一致
- 如果用户未指定消息内容，请先向用户确认要发送的内容
- 如果搜索不到目标联系人，请告知用户并请求提供更多信息
