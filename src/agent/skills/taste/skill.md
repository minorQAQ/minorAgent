# tasteskill：反 AI 模板化设计规范

> 适用范围：落地页、作品集、品牌站、PPT 设计（配色/字体/排版审美决策）。不适用于仪表盘、数据表格、多步表单等复杂产品 UI。
> 以下每条规则均**按场景触发**。先理解用户意图，再拉取相关规则。

---

## 0. 设计意图推断（动手之前先"读场"）

在写代码或调整参数之前，**先推断用户到底要什么**。

### 0.A 读取以下信号
1. **页面类型** — 落地页（SaaS / 消费品 / 代理商 / 活动）、作品集（开发者 / 设计师 / 创意工作室）、重设计（保留 vs 推倒）、编辑/博客、PPT 幻灯片。
2. **用户使用的氛围词** — "极简"、"沉稳"、"Linear 风格"、"高端"、"Apple 范"、"粗野主义"、"奢侈品"、"活泼"、"严肃 B2B"、"编辑感"、"代理商风格"、"玻璃质感"、"暗黑科技"。
3. **参考信号** — 用户链接的 URL、截图、提及的产品/品牌、竞争对手。
4. **受众** — B2B 采购团队 vs. 审美挑剔的消费者 vs. 招聘经理扫作品集。受众决定审美，不是你的个人品味。
5. **已有品牌资产** — Logo、色彩、字体、摄影。对于重设计，这些是起点材料，不是可选输入。
6. **隐性约束** — 无障碍优先的受众、公共部门、受监管行业、信任优先的商业、儿童产品。这些约束**覆盖审美偏好**。

### 0.B 生成一行"设计解读"再动手
写任何代码之前，用一行话声明：**"解读为：\<页面类型>，面向\<受众>，使用\<氛围>语言，偏向\<设计系统或审美流派>。"**

示例：
- *"解读为：B2B SaaS 落地页，面向技术买家，使用 Linear 极简语言，偏向 Tailwind + Geist + 克制动效。"*
- *"解读为：个人设计师作品集，面向招聘经理，使用编辑/动态字体语言，偏向原生 CSS + 滚动驱动动画 + 定制排版。"*

### 0.C 如果意图模糊，问一个澄清问题，不要猜
只问**一个**问题——仅在设计解读确实存在两个不同方向时才问。例如：*"这个应该更像 Linear 干净风还是更像 Awwwards 实验风？"*

如果可以自信地根据上下文推断，**不问**。直接声明设计解读并继续。

### 0.D 反默认纪律
不要默认使用：AI 紫色渐变、深色网格背景上居中的 Hero、三列等大功能卡片、无差别玻璃拟态、无限循环微动效、Inter + slate-900。这些都是 LLM 的默认模板。基于设计解读**刻意超越**它们。

## 1. 三大旋钮（核心配置）

在设计解读之后，设三个旋钮。以下每个布局、动效、密度决策都受这些旋钮约束。

* **`DESIGN_VARIANCE: 8`** — 1 = 完全对称，10 = 艺术化混沌
* **`MOTION_INTENSITY: 6`** — 1 = 静态，10 = 电影级 / 物理引擎
* **`VISUAL_DENSITY: 4`** — 1 = 美术馆 / 留白，10 = 驾驶舱 / 密集数据

**基准值：** `8 / 6 / 4`。如果设计解读未覆盖，用这些默认值。覆盖通过对话进行。

### 1.A 旋钮推断（设计解读 → 旋钮值）
| 信号 | VARIANCE | MOTION | DENSITY |
|---|---|---|---|
| "极简 / 干净 / 沉稳 / 编辑 / Linear 风格" | 5-6 | 3-4 | 2-3 |
| "高端消费品 / Apple 范 / 奢侈品 / 品牌" | 7-8 | 5-7 | 3-4 |
| "活泼 / 狂野 / 实验 / 代理商" | 9-10 | 8-10 | 3-4 |
| "落地页 / 作品集 / 营销站（默认）" | 7-9 | 6-8 | 3-5 |
| "信任优先 / 公共部门 / 无障碍关键" | 3-4 | 2-3 | 4-5 |
| "PPT 幻灯片" | 5-7 | 2-4 | 3-4 |

### 1.B PPT 场景特化规则
当为 PPT 制作提供审美指导时：
- **色彩**：适用第 4.2 节全部规则。优先中性底色 + 单一高对比度强调色。禁用 AI 紫/蓝渐变默认。
- **字体**：适用第 4.1 节（无衬线优先、禁用 Inter 默认、衬线极度克制）。
- **布局**：Card 规则（4.4）、密度规则（4.9）、反居中偏差（4.3）全部适用。
- **禁用的 AI Tell**：三列等大卡片、Inter 默认、紫/蓝霓虹光晕、每节标题上方的 eyebrow 小标签泛滥、em-dash（——）完全禁用。

## 2. 意图 → 设计系统映射

有了设计解读（第 0 节）和旋钮（第 1 节）后，选对基础。不为已有官方包的东西手写 CSS。

### 2.A 何时使用真正的设计系统
| 意图解读为… | 使用 | 原因 |
|---|---|---|
| Microsoft / 企业 SaaS / 仪表盘 | `@fluentui/react-components` | 官方 Fluent UI |
| Google 风格 / Material 风格产品 | `@material/web` + Material 3 tokens | 官方，可通过 Material Theming 定制主题 |
| IBM 风格 B2B / 企业分析 | `@carbon/react` | 官方 Carbon |
| GitHub 风格开发工具 / 社区页面 | `@primer/css` 或 `@primer/react-brand` | 官方 Primer |
| 公共部门 UK | `govuk-frontend` | 法规预期 |
| 现代 React 无障碍基础 | `@radix-ui/themes` | 原语 + 精炼主题 |
| Tailwind 现代 SaaS / AI 营销 | Tailwind + `dark:` variant | 独立小团队默认 |
| **PPT 设计** | 无框架 — 纯手工 SVG + 配色/字体规范 | 适用 taste 全部审美规则 |

**诚实原则**：如果一个系统适用，安装并使用**官方**包。不要手写其 CSS。

### 2.B 审美流派而非系统
对这些方向，**没有单一官方包**。用原生 CSS + Tailwind + 成熟组件库。

| 审美 | 诚实实现 |
|---|---|
| 玻璃拟态 | `backdrop-filter`，层叠边框，高光叠加。提供 `prefers-reduced-transparency` 降级方案 |
| Bento（Apple 风格磁贴网格） | CSS Grid 混合单元格大小 |
| 粗野主义 | 原生 CSS，等宽字体，原始边框 |
| 编辑/杂志 | 衬线体，不对称网格，大量留白 |
| 暗黑科技/黑客 | 等宽 + 霓虹强调色，终端元素 |

## 4. 设计工程指令（偏差修正）

LLM 默认产出陈词滥调。**主动覆盖**这些默认。每条规则都有场景感知的覆盖路径。

### 4.1 排版
* **展示/标题：** 默认 `text-4xl md:text-6xl tracking-tighter leading-none`。
* **正文字号 16px 基准，行高 1.6-1.7，最大宽度 65ch。**
* **无衬线字体选择：**
  * **不作为默认：** `Inter`。首选 `Geist`、`Outfit`、`Cabinet Grotesk`、`Satoshi`，或品牌合适的衬线体。
* **衬线纪律（极度不作为默认）：**
  * 衬线体**不作为任何项目的默认字体**。
  * 衬线体只有在以下**任一**条件明确为真时才可接受：
    - 品牌简介明确列举了某个衬线字体
    - 审美流派确实是编辑/奢侈/出版/手稿/传统/复古，且你能说清为什么这个特定衬线适合这个特定品牌
  * **明确禁用作为默认：** `Fraunces` 和 `Instrument_Serif`（两款 LLM 最爱的展示衬线）。
* **斜体下行字母留白（强制）：** 当斜体用于展示文字且词中包含下行字母（`y g j p q`）时，`leading-none` 会裁切。使用 `leading-[1.1]` 并加 `pb-1` 预留。发布前审查每一个展示标题中的斜体词。

### 4.2 色彩校准
* 最多 1 个强调色。饱和度默认 < 80%。
* **禁用 AI 紫/蓝辉光作为默认。** 无自动紫色按钮辉光，无随机霓虹渐变。使用中性底色（Zinc / Slate / Stone）搭配高对比度单一强调色（祖母绿、电光蓝、深玫红、焦橙色等）。
* **每项目一个调色板。** 不在同一项目中混用暖灰和冷灰。
* **色彩一致性锁定（强制）：** 一旦为页面选定强调色，整页都用它。

### 4.3 布局多样化
* **反居中偏差：** 当 `DESIGN_VARIANCE > 4` 时避免居中 Hero/H1。使用分屏、左对齐内容 / 右对齐资产、不对称留白。
* **PPT：** 封面可居中；内容页避免每一页都居中标题。

### 4.4 材质、阴影、卡片
* 只有当提升传达真正层级时才用卡片。否则用 `border-t`、`divide-y` 或负空间分组。
* 阴影要加底色偏色。浅色背景不用纯黑投影。
* **形状一致性锁定（强制）：** 页面只选**一个**圆角尺度。选项：全直角（0）、全柔角（12-16px）、全胶囊（交互元素全圆角）。混合系统仅在存在文档化规则且遵守时允许。

### 4.7 布局纪律（硬规则，违反即交付破损作品）

* **Hero 必须在首屏内可见。** 标题桌面端最多 2 行。
* **导航桌面端必须一行渲染，高度 ≤ 80px。**
* **3 列等大功能卡片禁用。** 用 2 列交错、不对称网格、滚动固定、水平滚动替代。
* **Bento 网格必须有节奏。** 不要堆叠 6 行左图右文。交替全宽行、不对称磁贴大小、垂直断点。
* **节间布局重复禁止。** 8 个节的落地页至少用 4 种不同布局家族。
* **Eyebrow 克制（强制）：** 最多每 3 节 1 个 eyebrow 小标签。Hero 算 1 节。数 `uppercase tracking` 实例，≤ ceil(节数/3) 则通过。

## 9. AI 痕迹（禁用的模式）

除非简介明确要求，否则避免以下签名。

### 9.A 视觉与 CSS
* **无霓虹/外发光** 作为默认。
* **无纯黑（`#000000`）。** 用 off-black、zinc-950 或 charcoal。
* **无过度饱和的强调色。**
* **无自定义鼠标光标。**

### 9.B 排版
* **避免 Inter 作为默认。**
* **不过度放大的 H1。**
* **衬线约束：** 编辑/奢侈/出版物用衬线。仪表盘不用。

### 9.C 布局与间距
* **数学式完美间距。**
* **无 3 列等大功能卡片。**
* **PPT 特化：** 无全页等大卡片网格。每页应有其自身节奏（anchor / dense / breathing）。

### 9.D 内容与数据
* **无泛用名。** 不用 "张三"、"李四"、"Acme"。
* **无假完美数字。** 避免 `99.99%`、`50%`。
* **无废话动词。** "赋能"、"无缝"、"释放"、"下一代" → 只用具体动词。

### 9.E em-dash 禁令（违规最多的痕迹）

**Em-dash（——）完全禁用。** 它是 LLM 的标志性风格拐杖。

* **标题中禁用。**
* **eyebrow / 标签 / 胶囊 / 按钮文字 / 图片标注 / 导航项中禁用。**
* **正文中禁用。**
* **引用归属中禁用。**
* **作为分隔符的 en-dash（–）也禁用。**

页面允许的破折号字符只有：
* 普通连字符 `-`
* 数学减号 `-5°C`

**此规则不可协商。** 如果输出中包含一个 `—` 或 `–` 在任何用户可见位置，输出不通过质量检查且必须重写。

## 14. 最终质量检查清单

输出前执行此矩阵。**不是可选的。逐条检查。**

- [ ] **意图推断**已声明（第 0.B 节的一句话）？
- [ ] **旋钮值**已显式声明并从意图推断？
- [ ] **设计系统**已选（如适用），或审美流派已诚实标记？
- [ ] **零 em-dash（`—`）整页任何位置。**
- [ ] **颜色一致性锁定：** 一个强调色全页一致使用？
- [ ] **形状一致性锁定：** 一个圆角体系一致应用？
- [ ] **按钮对比度检查：** 每个 CTA 文字对其背景可读？
- [ ] **衬线纪律：** 如果用了衬线，不是 Fraunces 或 Instrument_Serif？
- [ ] **无 AI 痕迹：** Inter 默认、AI 紫、三列等大卡片、em-dash？
- [ ] **Eyebrow 计数（机械）：** 数 `uppercase tracking` 实例 ÷ 节数，≤ ceil(节数/3)？
- [ ] **若无衬线默认：** 优先 Geist / Outfit / Cabinet Grotesk 等？
- [ ] **亮度模式**定义并测试？
- [ ] **移动端降级**对高差异布局显式声明？
- [ ] **一个设计系统**每项目（不混用 Material + shadcn）？

如果有任何一个复选框不能诚实打勾，页面没做完。修复后再交付。
