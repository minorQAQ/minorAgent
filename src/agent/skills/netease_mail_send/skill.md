# 网易邮箱邮件发送 Skill

## 适用场景

当用户需要发送邮件（通过网易163邮箱）时，Agent 应调用 skill_router 匹配此 skill，并严格遵循以下操作指南发送邮件。

## 前置准备

- 浏览器已安装并可正常使用
- 邮箱账号：19553226590，密码：@Qag73953

## 操作步骤

### 1. 打开网易邮箱并登录

1. 使用浏览器打开 `https://mail.163.com/`
2. 在登录页面输入账号 `19553226590` 和密码 `@Qag73953`
3. 点击登录按钮完成登录
4. 等待页面加载进入邮箱主页

### 2. 点击写信

1. 在邮箱主页左侧或顶部找到"写信"按钮
2. 点击"写信"按钮，进入写信页面

### 3. 填写邮件内容

1. **收件人**：在"收件人"输入框中输入收件人邮箱地址
2. **主题**：在"主题"输入框中输入邮件主题
3. **正文内容**：在添加附件下方的大面积空白输入框中输入邮件正文内容

### 4. 添加附件（如有需要）

1. 点击"添加附件"按钮
2. 在弹出的文件选择窗口中，在文件名输入框中粘贴或输入文件的完整路径地址
3. 点击"打开"确认选择文件
4. **等待附件上传完成**：需要确认页面上出现"上传完成"字样后，再进行下一步操作

### 5. 发送邮件

1. 点击页面上的"发送"按钮发送邮件
2. **如果页面上看不到"发送"按钮**：按空格键翻页，在下一页面中查找"发送"按钮，找到后点击发送
3. 确认邮件发送成功（页面提示发送成功）

## 注意事项

- 登录后请等待页面完全加载再进行操作
- 附件上传需等待"上传完成"提示出现后再点击发送，否则附件可能未成功添加
- 如果写信页面的发送按钮不在可见区域，按空格键翻页查找
- 正文输入框位于"添加附件"按钮下方的空白区域，注意区分与主题输入框的位置
