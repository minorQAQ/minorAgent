        新建定时任务

        该提示词将在每次触发时投递给 Agent 自主执行。 ⚠️ 定时任务无人值守执行：当前访问模式为「限制访问/权限审查」时，超出工作空间的操作会被拦截或退化拦截，建议先切换为「完全访问」。

        检测定时任务时间冲突的时间段长度，应用后热更新调度器。

        网络搜索

        搜索引擎

        web_search 工具使用的搜索引擎，仅支持以下选项。

        搜索 API Key

        所选搜索引擎的 API Key。

        邮件

        邮箱地址

        邮件发送账号，域名仅支持 qq.com / 163.com / 126.com / yeah.net。

        SMTP 授权码

        邮箱的 SMTP 授权码（非登录密码）。

        存储与数据库

        存储后端

        会话与定时任务的存储方式：JSON（本地文件）、MySQL（数据库）或 SQLite（本地数据库文件）。

        MySQL 连接配置

        存储后端的数据库连接信息；数据库类型由上方"存储后端"决定。

        MySQL 主机

        数据库主机地址（留空回退旧 MYSQL_HOST）。

        MySQL 端口

        数据库端口，默认 3306。

        MySQL 用户名

        数据库登录用户名。

        MySQL 密码

        数据库登录密码。

        MySQL 数据库名

        存放会话与定时任务数据的数据库。

        SQLite 文件路径

        存储库数据库文件；留空默认 history/sqlite/storage.sqlite。

        工具数据库类型

        数据库操作工具（text2sql / excel2sql）使用的数据库；与存储后端配置完全隔离，互不影响。

        MySQL 主机

        数据库主机地址。

        MySQL 端口

        数据库端口，默认 3306。

        MySQL 用户名

        数据库登录用户名。

        MySQL 密码

        数据库登录密码。

        MySQL 默认数据库

        工具连接默认使用的数据库（text2sql 仍按 database 参数指定目标库）。

        SQLite 路径（文件或目录）

        目录：每个库名对应一个 <目录>/<库名>.sqlite 文件；.sqlite 文件：所有操作使用该文件。留空默认 history/sqlite/tool。

        运行时参数

        LLM 上下文窗口

        上下文窗口大小（token），压缩阈值按窗口比例计算。

        上下文压缩阈值

        0~1，token 用量超过 窗口×该值 时触发压缩。

        截图缩放边长（px）

        工具截图 / 图片缩放边长，用于控制 token 消耗。

        RAG 分块大小（字符）

        文档检索的分块长度。

        RAG 分块重叠（字符）

        相邻分块的重叠长度。

        GUI 定位图像宽度（px）

        视觉定位模型输入图像宽度。

        GUI 定位图像高度（px）

        视觉定位模型输入图像高度。

        重复工具调用警告阈值

        同一工具连续重复调用超过该次数时输出警告。
